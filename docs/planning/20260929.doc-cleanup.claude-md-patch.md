# Documentation cleanup — proposed `.claude/CLAUDE.md` patch

`.claude/` is gitignored, so this branch cannot carry the change to
`.claude/CLAUDE.md` itself (phase 0, D4 item 4). This is the proposed change
for the owner to review and apply locally. It does four things:

1. **Renames `## Invariants` to `## Development rules`** and keeps only the
   rules for whoever changes the code, per phase 0 C2. The two system
   invariants (the NeoPixel gate and the `ntp_sync()` / `expiry_wall_time`
   rule) leave; they are rows S27 and S13 of the table in
   `docs/architecture.md#system-invariants`, and one link line replaces them.
   The kept rules are corrected and the C2 additions are made:
   - the IDF 6 component list now matches `main/CMakeLists.txt` and
     `components/ssd1680/CMakeLists.txt` (no LEDC; C6);
   - the `timer_defs_install()` rule is stated precisely;
   - the golden rule carries the regen caveat;
   - four new rules: `APP_MODE_TIMERS` stays 0, the layout-version bumps, the
     discovery schema bump, and the HA durability rule.

   The durability rule uses the **corrected** reason. C2's wording ("or the
   next document apply destroys it") is stale since BUG-6. The real reason is
   that the field has no off-device copy, so it is lost when NVS is rebuilt
   from the document (a defaults reseed or an unreadable timer table). This
   matches the comment above `FIELDS` in `main/ha_config.c`.
2. **Updates the reference-doc pointers** to the new layout: `architecture.md`
   plus `architecture/`, `product_overview.md` plus `behavior/`,
   `home_assistant/` and `agent_notes/`.
3. **Replaces the "delete `sdkconfig` and rebuild" advice** (C19). Deleting it
   loses every hand-set menuconfig value. The replacement follows
   `docs/developer_setup.md`: for new Kconfig options, snapshot it, run
   `idf.py reconfigure`, then diff; for one changed default, set that value in
   menuconfig. It points at the precedence probe in the same doc.
4. **Fixes the refactormain plan path**, which moved to
   `docs/planning/implemented/`.

## Applying it

From the main checkout, save the diff below to a file and run
`patch -p1 < claude-md.patch`. The blank context lines carry no leading
space (the trailing-whitespace hook would strip it); GNU `patch` accepts them
as context. Checked against the current `.claude/CLAUDE.md`: it applies
cleanly.
