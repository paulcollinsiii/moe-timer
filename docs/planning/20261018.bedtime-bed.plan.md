# Bed time: pixel-art bed — plan

Owner request 2026-10-18: the Bed Time lock shows the owner's pixel-art bed
with "zzz". Approved mockup: `20261018.bedtime-bed.mockup.png` beside this
file. Fourth sprite on the machinery from the charge-lock cat (33b4922),
time's-up Pikachu (507839c) and the break figure (35f8399, which added the
integer draw scale and ink colour: `build_sprite(scr, spr, x, y, scale,
ink)`): reuse `tools/gen_sprites.py`,
`main/sprite.c` and the sprite draw path — no new decoder or draw path.

## The art

`tools/sprites/bedtime_bed.png`, 29×23, 1-bit, black = ink (226 ink
pixels). Recovered by the coordinator from the owner's upscaled pixel-art
reference (its native grid, auto-picked as the cleanest downsample). The
reference is not in the repo. Generates `SPRITE_BEDTIME_BED`. The PNG is
placed in the working tree uncommitted and is committed with the
implementation, so every commit keeps `--check` green.

## Decisions — settled, do not re-litigate

1. **Drawn at 4×** (116×92) with the break figure's integer scale. The
   other three sprites and their goldens must stay byte-identical.
2. **Inverted screen**, as today: the bed is WHITE ink on black.
3. **Layout per the mockup**: bed at x = 4, y = 4. Right column, centred in
   the space right of the bed: "Bed Time" (Montserrat 28) above "Goodnight!"
   (Montserrat 28). "Brush teeth | Get water bottles" (Montserrat 18 — the
   smallest legible inverted size, per the existing comment) centred along
   the bottom, full width. The wording is unchanged from today; only the
   48 pt "Bed Time" shrinks to 28 (48 beside the bed overruns the panel).
   No new font.
4. Full refresh only (`display_bedtime()`), so no `CLEAN_BANDS` entry.
5. **Only the `bedtime` golden changes**; every other golden must be
   byte-identical (record sha256 before, compare after).
6. Pins as for the other sprites: ink count in Python, cited in C; golden
   window vs the PNG at 4× (each art pixel a 4×4 block), placement read from
   `display_screens.c`; a fit test (no ink within 2 px of any edge — this
   screen has no bleed exception) and the bed/words not overlapping.
