# Sprites at native scale (feat/sprite-native-scale)

Owner's request: remove all sprite scaling. break was drawn 2x (47x53 slot),
bedtime 4x (32x25 slot); now every sprite is 1:1 and the slots are panel size.

## Decisions

- `build_sprite()` lost its `scale` parameter; `sprite_draw_cb` no longer
  reads object user data; `BEDTIME_ART_SCALE` is gone. No dead scale=1 left.
- break slot 94x106 at (2, 2), unchanged box (x 2..95, y 2..107). It was
  already the 1x maximum: bar ink at x 100 (4 px gutter) stops the right,
  bottom row ink at y 110 stops the bottom with the 2 px exception, panel
  edge margin stops left/up. The 2 px bottom exception is KEPT: the box has
  always ended at y 107, and a 4 px gutter would cost it two rows.
- bedtime slot 131x105, origin moves (4, 4) -> (2, 2): box x 2..132, y 2..106
  (words' ink at x 137 and bottom line's at y 111 give the 4 px gutters; the
  panel margin gives the origin). Template art still on x 4..119, y 4..95.
- SLOT_INSET: break (2, 2), bedtime (2, 2) (clamped), charge (6, 0) as before.
  Old-size art (break 92x104, bedtime 128x100) lands at (4, 4) as before.
- Bedtime test windows: BEDTIME_TITLE_WIN_TOP was tied to BEDTIME_ART_Y (4);
  now a literal 4. BEDTIME_LINE_WIN_TOP 108 -> 111 (box bottom 106 + gutter).
- gen_sprites.py warns (stderr, never fails) when a break/bedtime image fits
  the old 47x53 / 32x25 box in a slot big enough to be the new one
  (OLD_SCALED_ART); documented in developer_setup.md.

## Data (sprite_data.c RLE bytes)

break 205 -> 413, bedtime 73 -> 305 (+440 B flash with the templates).
Ink: break 1105 -> 4420, bedtime 222 -> 3552.

## Proof

- goldens byte-identical (`git diff integration --stat -- test/test_display_render/golden` empty)
- owner overrides before/after, checked with scratch scripts that are not in the
  repo. To repeat: build the "before" sprite data with integration's generator
  and the original override PNGs (drawn at 2x/4x); build the "after" data with
  this branch's generator and the same PNGs converted to 1:1 (the conversion is
  a nearest-neighbour upscale by 2 for break, 4 for bedtime; every pixel
  becomes an exact block); then compare the two outputs, which must be identical.
