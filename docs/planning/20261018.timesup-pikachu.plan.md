# Time's up: surprised Pikachu — plan

Owner request 2026-10-18: the full-screen TIME'S UP (painted by
`display_timesup()` at the start of the expiry alarm) shows the surprised-
Pikachu meme. Approved mockup: `20261018.timesup-pikachu.mockup.png` beside
this file (layout A, bolder line). Second sprite on the machinery built for
the charge lock (`20261018.charge-lock-cat.plan.md`, commit 33b4922): reuse
`tools/gen_sprites.py`, `main/sprite.c` and the `display_screens.c` sprite
draw callback — add no second decoder or draw path. The break and bed-time
screens are NOT approved and are out of scope.

## The art

`tools/sprites/timesup_pikachu.png`, 178×124, 1-bit, black = ink, traced by
the coordinator from the owner's reference (the reference image is not in
the repo). It generates `SPRITE_TIMESUP_PIKACHU`; measured ~800 B encoded vs
2,852 B raw. Fan art, approved by the owner for this device.

## Decisions — settled, do not re-litigate

1. **Layout per the mockup.** Pikachu at the left, **flush with the bottom
   edge** (y = 128 − 124 = 4), x = 2. The reference is cropped open at the
   bottom (the meme framing): the head's side lines deliberately run off the
   panel's bottom edge. Right column, centred in the space right of the
   sprite: "TIME'S" in Montserrat 28 above "UP!" in Montserrat 48. **No new
   font.** The old empty bar under the words is dropped (the mockup has
   none). Not inverted. Full refresh (unchanged `display_timesup()`), so no
   `CLEAN_BANDS` entry.
2. **Edge rule with one stated exception.** Add a fits-the-panel test like
   the charge lock's: no TEXT ink within 2 px of any edge and no ink at the
   left/right/top edges, but ink IS expected on the bottom row inside the
   sprite's columns (assert it, so the bleed is intentional and pinned).
3. **Exact pixel pins**, as the fix pass did for the cat: the sprite's ink
   count inside its box equals the PNG's (asserted once in Python, cited in C
   comments), zero ink elsewhere in the sprite's columns, and
   `test_gen_sprites` checks the `timesup` golden's sprite window against the
   PNG pixel for pixel (take the placement from `display_screens.c`, not a
   literal). Generalise the existing cat-only checks rather than copy-paste
   where that stays readable.
4. **Only the `timesup` golden changes.** `MAGTAG_WRITE_GOLDEN=1` rewrites
   every golden: regenerate, then `git checkout` every other one, and confirm
   only `timesup.bin` is modified under golden/ (`charge_me.bin` must stay as
   committed in 33b4922).
5. The main screen's small "TIME'S UP" state label (`main_expired*`) is
   unchanged.
