## Decisions

- No script pins the Kconfig default to the header fallback: the only such
  script (`check-ack-hold-default.py`) was retired with stream B, and the
  remaining scripts are unrelated. Not invented here; a host test pins the
  fallback (10) instead, guarded `#ifndef CONFIG_MAGTAG_FULL_REFRESH_EVERY_N`.
- Forced-full paths (mode toggle, screen-kind change, break boundary, lock
  screen on glass, Button D) never reach `display_refresh_plan`: they call
  `display_full_refresh()` (or `wake_policy_render` answers FULL). Their
  independence of N is structural; pinned by signature `_Static_assert`s
  (plan takes counter + N only; `wake_policy_render` takes no counter) plus the
  existing named `test_wake_flow` cases.
- The counter reset after a forced full is `s_partial_count = 0` in display.c,
  which no host suite compiles. Pinned: from zero the next full is exactly N
  paints away.
